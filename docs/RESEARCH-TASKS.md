# Research tasks

Facts that need checking before a record, a wiki draft or a page can say them for certain: two sources
disagree, KOP's record looks wrong, or a draft had to guess. It supplements [PLAN.md](PLAN.md), which holds
the open work; this file holds the open questions. Any session that runs into one adds it here, in the same
commit as the work that found it, and takes it off (with what settled it) when it is answered.

Each task says what is in doubt, what each source says, where the answer goes once found (record id, wiki
draft, page), and who found it. KOP record ids are `facilities_v2` ids; wiki drafts are
`kop-pipeline/tmp/wiki-updates/drafts/<id>/`, reviewed at
[Submissions Review > Wiki updates](https://kidsoverprofits.org/admin-submissions/).
