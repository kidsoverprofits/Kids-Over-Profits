Flag SVGs in this directory were downloaded from FlagCDN, a service by Flagpedia:
https://flagcdn.com/

FlagCDN describes its files as vector flags based on Wikimedia Commons and asks
for a backlink to https://flagpedia.net/. The public legislation tracker links
to Flagpedia below the cards that use these images.

State files use the `state-{code}.svg` naming pattern. Country files use
`country-{code}.svg`. The federal U.S. flag uses `country-us.svg`.
