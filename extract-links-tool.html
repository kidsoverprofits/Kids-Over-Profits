Reddit Wiki Link Extractor

How to use:
  1. Go to a Reddit wiki page (e.g., /r/troubledteens/wiki/index/active-programs/)
  2. View the page source (Ctrl+U or right-click → "View Page Source")
  3. Copy ALL the source code
  4. Paste it into the textarea below
  5. Click "Extract Links"
  6. Copy the JSON output and add it to your tti-program-links.json file
